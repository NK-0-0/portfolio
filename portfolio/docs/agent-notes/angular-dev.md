- Deleting the last GLB (fully procedural scene) removes `public/models/` entirely, and `scripts/check-glb-budget.mjs` did an unguarded `readdirSync(MODELS_DIR)` → CI would crash with `ENOENT` on a *clean* repo. When you remove the last thing a script globs, guard the walk root with `existsSync` and no-op-pass. Also drop the script's `EXCEPTIONS` set the moment the exempted file is deleted, or the gate silently keeps trusting a name that no longer exists.
- This repo's interactive shell profile aliases `rm` to `trash` (not installed) — a bare `rm` inside Bash tool calls dies with `trash: command not found` (exit 127) and does NOT delete. Use `/usr/bin/rm` for scratch files, and `git rm` for tracked ones. (`@playwright/test` re-exports `chromium`, so `import { chromium } from '@playwright/test'` works without a separate `playwright` dep.)

- HDRI budget vs. Poly Haven reality: the ASSET_PIPELINE `< 512KB` HDRI budget is real but Poly Haven's *smallest* `.hdr` is 1k (a pure-sky night is ~1.3MB), so a straight download busts the budget — you must downsample. This machine has NO imagemagick/PIL/imageio/cv2, but `oiiotool` (OpenImageIO 3.1.x) IS installed and handles Radiance HDR: `oiiotool in.hdr --resize 512x256 -o out.hdr` (HDRIs are 2:1 equirect, so 512x256 keeps aspect). 1k→512px took a pure-sky night to 355KB, header stays `#?RADIANCE`. No gltf-transform needed for HDRIs.
- Working on a branch while a *concurrent* agent holds uncommitted changes in the SAME working tree: do NOT `git checkout -b` — it moves HEAD out from under them and their later commits land on your branch. Use `git worktree add -b <branch> <sibling-path> main` instead (fully non-disruptive; their tree/branch/uncommitted files untouched). The worktree has no `node_modules` (gitignored), which is fine for file-only/doc tasks that don't build; the new branch is still visible + mergeable from the main repo.
- Headless visual verification of a 3D change: drive the running dev server with Playwright, but two gotchas. (1) The `playwright` package only resolves from `portfolio/node_modules`, so a `.mjs` driver in the scratchpad fails `ERR_MODULE_NOT_FOUND` — write/run the script from inside `portfolio/` (delete after). (2) `DeviceCapabilityService` routes headless Chromium to the 2D fallback unless WebGL is real — launch with `args: ['--use-gl=angle','--use-angle=swiftshader','--enable-webgl','--ignore-gpu-blocklist']` and a desktop viewport (e.g. 1440x900). Assert `app-fallback` count is 0 and a `<canvas>` exists to confirm you're actually looking at the WebGL scene, then `scrollTo({behavior:'instant'})` + screenshot per beat.
- `beforeRender` (the non-deprecated angular-three@4.2.2 callback) is a literal alias of `injectBeforeRender` — `declare const injectBeforeRender: typeof beforeRender` (types line ~1863). Same signature, same `({ delta }) => {}` state arg; migrating a component is a pure rename, no behavioral difference. Procedural props (no GLB) don't need `injectLoader`/`loaderResource` at all — build the `Group`/meshes imperatively in the constructor (browser-guarded), expose via a `signal<Group|null>`, and render with `<ngt-primitive *args="[group()]" />` (still needs `NgtArgs` imported for `*args`).
- `@angular/router` is NOT a dead dependency despite the app defining no routes — `angular-three@4.2.2` statically imports it (`import * as i1 from '@angular/router'` for `NgtRoutedScene`) at the top of its fesm bundle, and does NOT declare it in peerDependencies. Removing it from package.json passes `npm install` but breaks `ng build` with `Could not resolve "@angular/router"`. Keep it installed; you can still drop `provideRouter`/`app.routes.ts` since `NgtRoutedScene` is never instantiated (this app uses `NgtCanvas` from `angular-three/dom`).
- `ng test --run` does NOT exist in the Angular 21 `@angular/build:unit-test` (Vitest) builder — errors `Unknown argument: run`. Use `ng test --no-watch` (watch also defaults to false in non-TTY/CI). CLAUDE.md/docs historically wrote `--run` (a Vitest-CLI-ism); it's wrong. Use `--no-watch` in CI workflows.
- Re-adding a removed `@angular/*` dep with a caret (`^21.2.0`) makes npm resolve the newest patch (e.g. router 21.2.17), whose peer wants `@angular/core@21.2.17` while the rest of the workspace is pinned to 21.2.15 → ERESOLVE. Fix: `git checkout -- package-lock.json` then `npm install` so npm honors the already-locked compatible version instead of bumping.
- `@gltf-transform/cli@4.4.1`: the `optimize` flag is `--texture-size <px>`, NOT the older `--texture-resize` shown in ASSET_PIPELINE.md (errors `Unknown option`). `--texture-compress ktx2` shells out to the external KhronosGroup `ktx` binary (KTX-Software) — fails at the `uastc` step if not on PATH. Fallback `--texture-compress webp` needs no external binary (smoke test: mask 2.91MB → 98KB).
